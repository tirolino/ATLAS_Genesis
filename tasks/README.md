# Planes de trabajo

- Para cada Issue, conserva análisis, criterios de aceptación y progreso en `issue-<numero>.md`.
- Para trabajo sin Issue, usa `todo.md`.
- No mezcles Issues paralelas ni incluyas secretos, claves, prompts privados o datos personales.
- Consulta [el flujo de Issues y Copilot](../docs/ISSUE_WORKFLOW.md).
