# Documentación

- Añade docstrings útiles a módulos y APIs públicas.
- Usa un estilo consistente, preferentemente Google style.
- Explica propósito, parámetros, retorno, excepciones y efectos secundarios cuando sean relevantes.
- Comenta decisiones y motivos no evidentes; no narres línea por línea el código.
- Actualiza README y documentación cuando cambien instalación, configuración, uso o contratos.
- Mantén los ejemplos sincronizados con la implementación.
